# Prácticas — TQA

Repositorio de las prácticas, ejercicios y archivos desarrollados durante las clases de la
materia de Testing y Aseguramiento de la Calidad (TQA).

## Organización

Cada práctica va en su propia carpeta, numerada en orden:

```
practica-01-<tema>/
practica-02-<tema>/
...
```

Cada carpeta incluye un `README.md` con el enunciado, lo realizado y las conclusiones.
